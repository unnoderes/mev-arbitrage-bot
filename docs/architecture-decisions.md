## ADR-001: 选择 TypeScript 而非 Rust

**状态**: 已采纳  
**日期**: 2024-10

**背景**  
需要选择链下机器人的开发语言。候选: TypeScript, Rust, Go, Python

**决策**  
选择 TypeScript

**理由**
1. **AI 编码友好**: GPT-3.5/Claude Haiku 对 TS 生成代码质量最高
2. **生态成熟**: ethers.js 是最流行的 Web3 库，文档完善
3. **开发速度**: 比 Rust 快 3-5 倍，适合 MVP 快速验证
4. **成本**: 低成本 AI 模型编码，TS 错误率更低

**代价**
- 性能不如 Rust (但 Polygon Gas 便宜，竞争不激烈，足够用)
- 内存占用较高 (~200MB vs Rust ~50MB)

**替代方案**  
Rust: 性能最佳，但开发周期长，AI 生成代码质量差

## ADR-002: 使用 Alchemy 免费版而非自建节点

**状态**: 已采纳

**决策**  
使用 Alchemy 免费版 RPC，不自建 Polygon 节点

**理由**
1. **零成本**: 免费额度足够 MVP 使用
2. **免运维**: 不需要同步节点、管理磁盘
3. **稳定性**: Alchemy 可用性 > 99.9%
4. **快速启动**: 注册即用，无需等待同步

**代价**
- 延迟稍高 (200-500ms vs 自建 10-50ms)
- 依赖第三方服务

**未来优化**  
如果日均利润 > $50，升级到 Alchemy 付费版或自建节点

## ADR-003: MVP 阶段不使用闪电贷

**状态**: ❌ 已被取代 → [ADR-0001](./adr/0001-balancer-flash-loans.md)

> 取代理由：Aave V3 的 0.05% 溢价构成硬性利润地板，借 10,000 美元要付 5 美元，
> 而 Balancer V2 的闪电贷在 Polygon 上实测费率为 0。零费率下没有理由不用杠杆。

**决策**  
初期用自有资金 (50-100 USDC) 套利，不集成闪电贷

**理由**
1. **降低复杂度**: 闪电贷需要额外合约逻辑和调试
2. **足够验证**: 小资金足以验证策略和盈利能力
3. **Gas 成本**: 闪电贷 Gas 更高，小额套利不划算

**未来扩展**  
验证盈利后，添加闪电贷模块实现零本金套利

## ADR-004: Dashboard 可选，CLI 优先

**状态**: 已采纳

**决策**  
CLI 作为主要交互方式，Dashboard 作为可选功能

**理由**
1. **简化 MVP**: 减少前端开发工作量
2. **运维便利**: SSH 远程也能管理
3. **日志优先**: CSV 日志已足够分析

**实施**  
- Phase 1: 只做 CLI + 日志
- Phase 2: 有需求再加 Dashboard

## ADR-005: 原子化交易而非分步执行

**状态**: 已采纳

**决策**  
所有 swap 步骤在一个链上交易内完成

**理由**
1. **零风险**: 要么全成功，要么全回滚
2. **防抢跑**: 不会被 MEV 机器人夹击
3. **Gas 优化**: 一次交易比多次便宜

**实施**  
智能合约的 `triangularArbitrage()` 函数包含全部逻辑

## ADR-006: 监控 9 个核心交易池

**状态**: ❌ 已被取代 → [ADR-0002](./adr/0002-v3-primary.md)

> 取代理由：这张表是空的。SushiSwap 的 USDC/WETH 池只有 0.08 USDC 与 0 WETH；
> QuickSwap 的 USDC/WPOL 池只有 671 USDC。真正的流动性在 Uniswap V3 的 0.05% 档。
> 池子也不再硬编码，改为从工厂枚举 + 深度下限过滤。

**决策**  
初期只监控 3 个 DEX × 3 个交易对 = 9 个池子

**交易对**
- USDC/WETH
- USDC/MATIC
- WETH/MATIC

**DEX**
- QuickSwap
- Uniswap V3
- SushiSwap

**理由**
1. **高流动性**: 这些是 Polygon 上最活跃的交易对
2. **低竞争**: 比 ETH 主网竞争小
3. **计算可控**: 9 个池子 → 最多 27 条三角路径，计算量小

**未来扩展**  
根据实际数据，增加 Balancer、Curve 等
