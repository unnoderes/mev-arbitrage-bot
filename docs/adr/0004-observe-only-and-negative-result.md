# 先只观测，并把「当前交易对不可套利」作为可交付的结论

状态: accepted

Polygon 上的套利竞争由专业机器人主导，在没有数据前投入私有交易通道或实盘资金都是猜测。因此本期只交付只观测模式：记录每个区块的最佳毛利润、对应路由与规模，用 `eth_call` 在下一区块状态上模拟真实 `execute()` 来给出「本会赢」的上界，不发送任何交易、不读取私钥。

## 负结果

实测已经给出一个可复现的负结果，因此它本身就是交付物的一部分，而不是失败：在 {USDC, USDCe, WETH, WPOL} 四个代币、15 个 Uniswap V3 池子（5 个交易对 × 3 个费率档）上枚举全部闭环，连续 30 个区块内没有任何规模（10–5,000 计价单位）能盈利。0.05% 档的往返手续费地板是 0.15%，而真实价差不足以覆盖它。

## 代价

- 这套东西在扩交易对之前不会产生利润，只能产生证据。
- 「边际为正」的闭环在每个区块有 32 条，全部是薄池子的假象；如果不用深度下限过滤，仪器会持续自欺。
- 扩交易对是下一期的事，且会显著放大搜索空间。
